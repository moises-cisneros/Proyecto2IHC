## Resumen de Cambios

Implementación de la capa backend para la portabilidad de datos del usuario, las reglas de dominio para la baja honesta de cuenta y la prevención de eliminación destructiva de planes con pendientes, conforme a los requisitos de la **Clase 22 (Patrones Oscuros / Salida Honesta)** y la planificación de la **Tarea 10**.

### 1. Portabilidad de Datos (`UserDataExportService`)

- Extracción estructurada de perfil, planes organizados, planes participados, invitaciones, votos emitidos y balances históricos de gastos y liquidación.
- Soporte para exportación en formatos **JSON** y **CSV** normalizados.
- Protección estricta de credenciales y datos sensibles (cero contraseñas o tokens expuestos).

### 2. Regla Difícil de Baja de Cuenta (`User::puedeEliminarCuenta()`, `User::eliminarCuenta()`)

- Validación de bloqueo si el usuario organiza planes abiertos (`propuesta`, `votando` o `pendiente`): código `planes_abiertos_organizados`.
- Validación de bloqueo si el usuario mantiene saldos deudores pendientes en gastos de planes activos: código `deudas_pendientes_gastos`.
- Ejecución de baja lógica: inhabilitación de credenciales (`activo = false`, hash invalidado) y aplicación de `softDeletes` para impedir futuros inicios de sesión en `AutentificacionController`.

### 3. Regla Difícil de Eliminación de Plan (`Plan::puedeEliminarse()`)

- Validación de bloqueo si el plan se encuentra en estado `confirmado` (`plan_confirmado`).
- Validación de bloqueo si el plan posee gastos con deudas pendientes entre participantes (`deudas_pendientes_gastos`).
- Detección de `url_accion` sugerida para redirigir directamente a la liquidación sin callejones sin salida (_anti-roach motel_).

### 4. Dominio de Desvinculación de Invitaciones (`Invitacion::rechazar()`)

- Método en modelo `Invitacion` y autorización en `PlanPolicy` (`rechazar`) para permitir al usuario invitado declinar la invitación.

### Verificación y Cobertura

- 10 tests unitarios en `tests/Unit/SalidaHonestaDominioTest.php` pasando al 100%.
- Linteo con Laravel Pint aprobado.
- Regla de cero atribución de IA y autoría verificada.
